📋 Cómo configurar Google Sheets (pasos)
  1. Abre sheets.google.com y crea una hoja nueva
  2. Menú Extensiones → Apps Script
  3. Borra el código existente y pega el código que está abajo
  4. Guarda (💾) → Implementar → Nueva implementación
  5. Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquier usuario
  6. Copia la URL que aparece y pégala arriba
